# Iris Classification

A beginner-friendly machine learning project that trains an Iris flower classification model and exposes predictions through a Streamlit application.

## ✨ Features

- Train an Iris classification model
- Run predictions through a simple Streamlit UI
- Reproducible Python setup with `requirements.txt`
- Clear separation between training and application code

## 🧰 Tech Stack

- Python
- Machine Learning
- Streamlit

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/kaptan009/CodeAlpha_Iris_Classification.git
cd CodeAlpha_Iris_Classification
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Train the model

```bash
python src/train.py
```

### 4. Launch the application

```bash
streamlit run app/app.py
```

## 🎯 Purpose
